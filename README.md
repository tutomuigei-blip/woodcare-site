# woodcare-site（合同会社ウッドケア 公開ホームページ）

会社の公開サイトです。GitHub Pages で公開しています。

- **公開 URL**：https://tutomuigei-blip.github.io/woodcare-site/
- **リポジトリ**：GitHub `tutomuigei-blip/woodcare-site`
- 静的な HTML/CSS のみ（ビルド不要・サーバー不要）

---

## ⚠ ここは「外から誰でも見える場所」です

**利用者の個人情報を 1 文字も置かないでください。**
氏名・被保険者番号・生年月日・要介護度・担当ケアマネ、
それらを含む CSV・PDF・写真・スクリーンショットも同じです。

業務アプリ（`~/apps/` と `~/gas/`）とは**完全に別**のものとして扱ってください。
業務アプリのファイルをここへコピーしない、ここのファイルを業務アプリへ混ぜない。

---

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | トップ（会社紹介・採用の帯・DX ルーム） |
| `company.html` | 会社概要 |
| `kaigo.html` | 介護事業の紹介 |
| `dx.html` | IT・DX の取り組み |
| `recruit.html` | 採用 |
| `contact.html` | お問い合わせ（相談チャネル・地図・応募フォーム） |
| `style.css` | 見た目（色の定義はここ 1 か所） |
| `images/` `videos/` | 素材 |
| `サイト構築ログ.md` | 制作の記録 |

## 直し方

1. HTML/CSS を直す
2. ブラウザでファイルを直接開いて確認する（サーバーは要りません）
3. コミットする
4. **`main` に push すると GitHub Pages が自動で公開します**

> push した内容は**すぐ世界中から見えます**。
> 公開してよい内容かどうかを、push の前に必ず確かめてください。

## 確認しておくとよいこと

- 写真に、利用者・職員の顔や名札、書類が写り込んでいないか
- 電話番号・住所は、公開してよいもの（事業所のもの）か
- リンク切れがないか

## 補足

- 独自ドメインは設定していません（`CNAME` なし）。既定の `github.io` ドメインです。
- `サイト構築ログ.md` には「公開の手配は別途」と書かれたまま残っていますが、
  **実際にはすでに公開済み**です。
